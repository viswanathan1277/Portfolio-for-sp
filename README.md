## Deployment Instructions
1. Push `index.html` and `style.css` to the root of your GitHub repository named `portfolio`.
2. Go to repository **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your site will be live at `https://viswanathan1277.github.io/portfolio/`.
